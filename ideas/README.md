# Idea files

Each file develops one research question for the project in `../project.docx`.
They appear here in the order they were written. Later files build on earlier
ones.

| File | Question | Status |
| --- | --- | --- |
| [candidate-topics.md](candidate-topics.md) | 16 candidate topics from the first survey of the sources, with a toolbox of computational methods | Starting list |
| [shimla-hill-states-sutlej.md](shimla-hill-states-sutlej.md) | How did the growth of Shimla draw labour, land and water from the Shimla Hill States along the Sutlej, and what changed after the 1948 merger? | Set aside |
| [begar-land-caste-12-villages.md](begar-land-caste-12-villages.md) | Did the end of princely rule change who worked for whom? The begar question over 12 villages | Replaced by the 5-village version |
| [begar-land-caste-5-villages.md](begar-land-caste-5-villages.md) | The same begar, land and caste question over five villages | Alternative |
| [joint-household-himachal.md](joint-household-himachal.md) | Why did hill households stay joint, in some villages through fraternal polyandry, and why was the practice declining by 1961? | Alternative |
| [seasonal-herding-himachal.md](seasonal-herding-himachal.md) | How did seasonal herding shape life in the Himachal hills from 1881 to 1961, and who controlled and profited from it? | Basis of the current question |
| [two-valleys-sutlej-ravi.md](two-valleys-sutlej-ravi.md) | How did the upper Sutlej and the Ravi organise the same herding economy differently, and what changed after the Forest Department took over the pastures and the Tibet border closed? | Current question |

`candidate-topics.md` was written before the page-reference tool existed. Its
source references use an older folder name and are not checked. The last two
files cite PDF pages throughout. `../scripts/pageref.py` finds the page of any
quote. `../sources.md` lists every source.
